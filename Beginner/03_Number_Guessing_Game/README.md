# Number Guessing Game

## Overview

A game where the player attempts to guess a randomly generated number.

## Learning Objectives

- Practice loops
- Use conditionals
- Generate random numbers

## Concepts Covered

- while loops
- if statements
- random module

## Features

- Random number generation
- Unlimited guesses
- Win message

## How to Run

```bash
python main.py
```

## Future Improvements

- Difficulty levels
- Guess counter
- High score system
