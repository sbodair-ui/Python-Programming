# Tip Calculator

## Overview

Calculates the tip amount and total bill based on user input.

## Learning Objectives

- Perform mathematical calculations
- Accept numerical input
- Format currency output

## Concepts Covered

- Variables
- Arithmetic
- User input

## Features

- Tip percentage
- Total bill
- Cost per person

## How to Run

```bash
python main.py
```
