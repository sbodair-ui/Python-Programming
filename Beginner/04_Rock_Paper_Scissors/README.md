# Rock Paper Scissors

## Overview

Play Rock, Paper, Scissors against the computer.

## Learning Objectives

- Practice decision making
- Compare user and computer choices
- Generate random choices

## Concepts Covered

- if/elif/else
- random module
- Strings

## Features

- Player vs Computer
- Random computer moves
- Winner detection

## How to Run

```bash
python main.py
```

## Future Improvements

- Best-of-five mode
