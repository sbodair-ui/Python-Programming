# Temperature Converter

## Overview

Convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Learning Objectives

- Create reusable functions
- Perform mathematical conversions

## Concepts Covered

- Functions
- Parameters
- Return values

## Features

- Celsius ↔ Fahrenheit
- Celsius ↔ Kelvin
- Fahrenheit ↔ Kelvin

## How to Run

```bash
python main.py
```
