# Hangman

## Overview

A classic word guessing game played in the terminal.

## Learning Objectives

- Work with strings
- Manage game loops
- Practice problem solving

## Concepts Covered

- Lists
- Strings
- Loops
- Conditionals

## Features

- Random words
- Letter guessing
- Win/Lose detection

## How to Run

```bash
python main.py
```

## Future Improvements

- Difficulty levels
- Categories
- ASCII art graphics
