# Contact Book

## Overview

A simple contact management application that stores names and phone numbers.

## Learning Objectives

- Store structured data
- Perform CRUD operations
- Search data

## Concepts Covered

- Dictionaries
- Functions
- Loops

## Features

- Add contacts
- View contacts
- Search contacts
- Delete contacts

## How to Run

```bash
python main.py
```

- Edit existing contacts
