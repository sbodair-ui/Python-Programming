# Calculator

## Overview

A simple calculator that performs basic arithmetic operations using user input.

## Learning Objectives

- Accept user input
- Perform arithmetic calculations
- Display formatted output

## Concepts Covered

- Variables
- Data types
- User input
- Arithmetic operators
- Type conversion

## Features

- Addition
- Subtraction
- Multiplication
- Division

## How to Run

```bash
python main.py
```
